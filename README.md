# 🧮 Calculadora em C

Programa desenvolvido em linguagem C que realiza as quatro operações matemáticas básicas entre dois números inteiros.

## 📋 Funcionalidades
- ➕ Soma
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão inteira

## 💡 Exemplo de uso
Digite dois Numeros: 10 2

 Soma = 12
 
 Subtracao = 8
 
 Multiplicacao = 20
 
 Divisao = 5
